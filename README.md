# GTO Local · 本地德州扑克 GTO 求解器

纯 Python 实现的德州扑克 GTO 求解器，对标 GTO Wizard 的核心体验：
**选牌桌（Cash/MTT、2/6/9 人桌）→ 选位置构建翻前行动线（自动带出双方范围）→ 选街道（翻牌/转牌/河牌）→ MCCFR 实时求解 → 13×13 策略矩阵可视化**。完全离线，无需 GPU。

> 范围说明：任意桌型下**翻后只解 HU（单挑）**——行动线中其余玩家全部弃牌，最终两人进入翻牌圈。多人池（3-way+）不在本工具范围。

## 功能总览

| 模块 | 说明 |
|---|---|
| **翻/转/河通用求解器** | 外部采样 MCCFR + 机会节点采样，从任意街道解到摊牌，逐组合无抽象 |
| **翻前模块（2/6/9 人桌）** | Cash/MTT 配置、位置序列（UTG~BB）、行动线构建器（加注/3bet/4bet/跟注/弃牌，自动绕桌行动）、第三人入池封锁（保证 HU 结局）、按位置的 GTO 近似参考范围自动填充 |
| **短码 Nash 全下表** | HU jam/fold 纳什均衡（1~20bb），169×169 胜率矩阵 + 最优应对迭代 |
| **13×13 策略矩阵 UI** | 动作频率堆叠着色、组合级明细、节点树导航（含转/河牌采样节点） |
| **Equity 计算器** | 手牌 vs 范围蒙特卡洛胜率 |
| **Kuhn 验证器** | 用解析纳什均衡证明 CFR 引擎正确性 |

## 快速开始（详细教程 · 小白向）

只需要 **Python 3.10+** 和一台能上网的电脑（Windows / Mac / Linux 都行），全部操作约 5 分钟。求解完全在本地 CPU 运行，不需要显卡，装完后离线也能用。

### 第 1 步：安装 Python

- **Windows**：打开 https://www.python.org/downloads/ 下载最新版安装包。安装时**务必勾选最下方的 `Add python.exe to PATH`**（不勾选后面会报"python 不是命令"），然后点 Install Now。
- **Mac**：`brew install python@3.13`，或用官网安装包。
- 装完后打开终端（Windows 按 `Win+R` 输入 `cmd` 回车），输入下面命令能看到版本号（≥3.10）就 OK：

```bash
python --version
```

> Windows 上如果提示"不是内部或外部命令"：关掉终端重开一个试试；还不行就用 `py --version`，后面所有命令里的 `python` 都换成 `py`。

### 第 2 步：下载本项目代码

两种方式任选其一：

**方式 A（推荐，装了 git）**：

```bash
git clone https://github.com/salafur/gto-local.git
cd gto-local
```

**方式 B（不用 git）**：浏览器打开 https://github.com/salafur/gto-local → 点绿色 **Code** 按钮 → **Download ZIP** → 解压到任意目录 → 在终端里 `cd` 进解压后的文件夹（如 `cd C:\Users\你的用户名\Downloads\gto-local-main`）。

### 第 3 步：创建虚拟环境并安装依赖

在项目目录里执行（逐行复制）：

```bash
python -m venv .venv
```

然后**激活虚拟环境**（每次使用前都要激活一次）：

| 系统 | 命令 |
|---|---|
| Windows (cmd) | `.venv\Scripts\activate.bat` |
| Windows (PowerShell) | `.venv\Scripts\Activate.ps1` |
| Mac / Linux | `source .venv/bin/activate` |

激活后命令行前面会出现 `(.venv)` 字样。接着安装依赖：

```bash
pip install -r requirements.txt
```

> 国内网络慢的话用清华镜像加速：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

> PowerShell 激活脚本报红字"禁止运行脚本"时，先执行一次：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，再重新激活。

### 第 4 步：启动并打开界面

```bash
python -m web.server
```

看到 `GTO Local 已启动: http://127.0.0.1:8000` 后，**用浏览器（Chrome/Edge）打开 http://127.0.0.1:8000** 即可使用。终端窗口不要关，关了服务就停了；停止服务按 `Ctrl+C`。

### 常见问题（FAQ）

| 问题 | 解决办法 |
|---|---|
| 打开网页提示无法访问 | 确认终端里服务还在运行；地址必须是 `http://127.0.0.1:8000` |
| 启动报错"端口被占用"（10048） | 换端口启动：`python -m web.server --port 8001`，然后浏览器访问对应端口 |
| 求解要等多久？ | 河牌 20 万迭代约 2-10 秒，转牌约 10-30 秒，翻牌 100 万+迭代约 1-3 分钟（纯 CPU，迭代期间可以切出去玩别的） |
| Nash 表第一次点"计算"很慢 | 首次要构建 169×169 胜率矩阵（约 40 秒），之后永久缓存，秒出 |
| 求解/安装需要联网吗？ | 只有 `pip install` 那一步需要联网，之后完全离线可用 |
| 杀毒软件/防火墙弹窗 | 是本地 Python 进程，允许即可；本工具不联网、不收集任何数据 |

## 使用流程（常规局）

1. **牌桌设置**：Cash / MTT、桌型（HU / 6-max / 9-max）、盲注、前注、有效筹码。
2. **翻前行动线**：按位置顺序逐步点选各玩家动作（UTG 先行动，绕桌进行），系统自动算出翻后底池、后手、OOP/IP，并填充双方参考范围（可自由修改）。已有两人入池后，其余位置只能弃牌（保证 HU 结局）。
3. **公共牌**：输入 3 张 = 翻牌圈，4 张 = 转牌圈，5 张 = 河牌圈。
4. **求解**：迭代次数建议 —— 河牌 20 万 / 转牌 50 万 / 翻牌 100 万+。结果按节点浏览，矩阵点格子看组合明细。

**示例（6-max）**：UTG 加注 2.2bb → HJ/CO 弃牌 → BTN 跟注 → SB/BB 弃牌 ⇒ 底池 5.9bb、后手 97.8bb，OOP=UTG（RFI 16.7%）vs IP=BTN（平跟 10%）。

**短码 Nash 表**：切到「短码 Nash」页签，滑块选筹码深度即可。首次运行需构建胜率矩阵（约 40 秒），之后永久缓存到 `~/.gto-local/`。

## 求解质量与迭代建议

翻牌圈求解的信息集数量随转牌/河牌采样爆炸式增长，这是无抽象精确求解的固有代价：

| 起始街道 | 建议迭代 | 参考耗时* |
|---|---|---|
| 河牌（5 张） | 10-50 万 | 2-10 秒 |
| 转牌（4 张） | 30-100 万 | 10-30 秒 |
| 翻牌（3 张） | 100-300 万 | 1-3 分钟 |

\* 典型中端范围（每方 300-600 组合）。迭代不足时策略会有噪声，表现为相邻组合频率抖动。

## 算法说明

**MCCFR（外部采样）**：每次迭代选定遍历方，等概率采样其一个组合（保证低频组合被充分训练），按权重采样对手组合；在遍历方节点展开全部动作、更新遗憾值与平均策略，在对手节点按当前策略采样单个动作。街道关闭（双方过牌/跟注）而公共牌未发完时进入**机会节点**，从剩余牌堆采样下一张公共牌继续。两人零和博弈下 CFR 保证平均策略收敛到纳什均衡。

**Nash 全下表**：SB 只能全下/弃牌、BB 只能跟注/弃牌的简化博弈。先用蒙特卡洛构建 169×169 手牌类胜率矩阵（对称填充 + 磁盘缓存），再做 fictitious-play 风格的最优应对迭代（带阻尼 + 后段平均）。10bb 结果 push 57.5% / call 36.8%，与公开 Nash 表一致。

**正确性基准**（Kuhn 扑克，有解析纳什解的玩具博弈）：

```
博弈值: -0.0556（理论 -1/18 = -0.0556）✓
exploitability: 0.0006（理论 0）✓
拿 K 先行动下注 66%，拿 J 下注 22% —— 恰好 3α 与 α 的理论比例 ✓
```

评估器采用点数统计 + 位掩码顺子检测的快速实现，与 21 组合暴力枚举有 3000 组随机牌等价性测试，速度提升约 11 倍。

## 范围语法

```
AA        对子（6 组合）        22+       22 及以上所有对子
ATs+      ATs..AKs（非连张：高牌固定升低牌）
76s+      76s..KQs（连张：整体提升）
KQo       不同花 KQ            AK        同花+不同花全部
random    全部 1326 组合        AKs:0.5   权重（一半频率）
random,-TT+,-AKs   减法语法：从范围中移除
```

```
gto/
├── cards.py       # 牌的表示与解析

web/
├── server.py      # FastAPI 后端（异步任务 + 进度轮询）
└── static/        # 13×13 策略矩阵 UI
tests/             # 79 个测试
```
