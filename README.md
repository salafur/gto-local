# GTO Local · 本地德州扑克 GTO 求解器

纯 Python 实现的 HU（单挑）德州扑克 GTO 求解器，对标 GTO Wizard 的核心体验：
**选牌桌（Cash/MTT）→ 构建翻前行动线（自动带出双方范围）→ 选街道（翻牌/转牌/河牌）→ MCCFR 实时求解 → 13×13 策略矩阵可视化**。完全离线，无需 GPU。

## 功能总览

| 模块 | 说明 |
|---|---|
| **翻/转/河通用求解器** | 外部采样 MCCFR + 机会节点采样，从任意街道解到摊牌，逐组合无抽象 |
| **HU 翻前模块** | Cash/MTT 配置（盲注/前注/筹码预设）、行动线构建器（limp/加注/3bet/4bet）、GTO 近似参考范围自动填充 |
| **短码 Nash 全下表** | HU jam/fold 纳什均衡（1~20bb），169×169 胜率矩阵 + 最优应对迭代 |
| **13×13 策略矩阵 UI** | 动作频率堆叠着色、组合级明细、节点树导航（含转/河牌采样节点） |
| **Equity 计算器** | 手牌 vs 范围蒙特卡洛胜率 |
| **Kuhn 验证器** | 用解析纳什均衡证明 CFR 引擎正确性 |

## 使用流程（常规局）

1. **牌桌设置**：Cash / MTT、盲注、前注、有效筹码（预设 100bb cash ~ 8bb MTT）。人数当前仅 HU，多人池 roadmap。
2. **翻前行动线**：逐步点选 BTN(SB)/BB 的动作（弃牌/平跟/加注到 X bb/3bet/4bet/跟注），系统自动算出翻后底池、后手，并填充双方参考范围（可自由修改）。
3. **公共牌**：输入 3 张 = 翻牌圈，4 张 = 转牌圈，5 张 = 河牌圈。
4. **求解**：迭代次数建议 —— 河牌 20 万 / 转牌 50 万 / 翻牌 100 万+。结果按节点浏览，矩阵点格子看组合明细。

**短码 Nash 表**：切到「短码 Nash」页签，滑块选筹码深度即可。首次运行需构建胜率矩阵（约 40 秒），之后永久缓存到 `~/.gto-local/`。

## 求解质量与迭代建议

翻牌圈求解的信息集数量随转牌/河牌采样爆炸式增长，这是无抽象精确求解的固有代价：

| 起始街道 | 建议迭代 | 参考耗时* |
|---|---|---|
| 河牌（5 张） | 10-50 万 | 2-10 秒 |
| 转牌（4 张） | 30-100 万 | 10-30 秒 |
| 翻牌（3 张） | 100-300 万 | 1-3 分钟 |

\* 典型中端范围（每方 300-600 组合）。迭代不足时策略会有噪声，表现为相邻组合频率抖动。

## 算法说明

**MCCFR（外部采样）**：每次迭代选定遍历方，等概率采样其一个组合（保证低频组合被充分训练），按权重采样对手组合；在遍历方节点展开全部动作、更新遗憾值与平均策略，在对手节点按当前策略采样单个动作。街道关闭（双方过牌/跟注）而公共牌未发完时进入**机会节点**，从剩余牌堆采样下一张公共牌继续。两人零和博弈下 CFR 保证平均策略收敛到纳什均衡。

**Nash 全下表**：SB 只能全下/弃牌、BB 只能跟注/弃牌的简化博弈。先用蒙特卡洛构建 169×169 手牌类胜率矩阵（对称填充 + 磁盘缓存），再做 fictitious-play 风格的最优应对迭代（带阻尼 + 后段平均）。10bb 结果 push 57.5% / call 36.8%，与公开 Nash 表一致。

**正确性基准**（Kuhn 扑克，有解析纳什解的玩具博弈）：

```
博弈值: -0.0556（理论 -1/18 = -0.0556）✓
exploitability: 0.0006（理论 0）✓
拿 K 先行动下注 66%，拿 J 下注 22% —— 恰好 3α 与 α 的理论比例 ✓
```

评估器采用点数统计 + 位掩码顺子检测的快速实现，与 21 组合暴力枚举有 3000 组随机牌等价性测试，速度提升约 11 倍。

## 范围语法

```
AA        对子（6 组合）        22+       22 及以上所有对子
ATs+      ATs..AKs（非连张：高牌固定升低牌）
76s+      76s..KQs（连张：整体提升）
KQo       不同花 KQ            AK        同花+不同花全部
random    全部 1326 组合        AKs:0.5   权重（一半频率）
random,-TT+,-AKs   减法语法：从范围中移除
```

## 项目结构

```
gto/
├── cards.py       # 牌的表示与解析

web/

└── static/        # 13×13 策略矩阵 UI
tests/             # 63 个测试
```
